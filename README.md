# JHPCN 2027年度 公募・申込書Q&A

応募資格や計算資源の選び方、申込書の書き方を、JHPCNの募集要項とWord・Excelの様式に沿って質問するためのスキルです。回答から、根拠となったページや記入欄に戻って確認できます。

## 外部リンクを開けないチャットで質問する

1. 応募者がブラウザで[対象資料](#対象資料)から募集要項PDFを保存し、チャットに添付します。申込書の書き方を聞く場合は、該当するWordまたはExcelの様式も添付します。
2. 次の枠内を貼り付け、最後の質問を書き換えます。スキルのインストールやGitHubへの接続は不要です。

```text
JHPCN 2027年度公募について、添付資料または私が貼った原文だけで答えてください。外部リンクやWeb検索は使わないでください。
公募条件は募集要項を根拠に、結論と節・冊子ページを示してください。申込書の記入方法は、Wordの項目名またはExcelのシート名・欄名を添えてください。
計算資源の規模を聞かれたら、第9.1節の申請上限を条件と金額付きで先に示し、第9.3節の採択後の提供量の扱いを添えてください。
資料が足りない場合は、必要な節や記入欄だけを求めてください。抜粋にない情報を資料全体にないと断定しないでください。

質問：この公募でどれくらいの計算資源を申請できますか？
```

**添付も使えない場合**は、同じチャットに該当箇所の原文を貼ります。見出し・ページ番号・表の列名・単位・脚注を一緒に含めてください。例えば資源量の質問なら、第9.1節「申請資源量の上限」と第9.3節「提供資源量」です。Excelのセル番地を聞く場合は、シート名と行・列番号も添えてください。

## URLを直接開けるチャットで質問する

ChatGPTまたはCopilotの新しいチャットに、下の枠内をまとめてコピーしてください。最後の一行を自分の質問に替えられます。インストールは不要です。

```text
次のスキルに従ってください。公募条件・金額・計算資源に関する回答の根拠は、下記の募集要項PDF（別紙を含む）だけに限定してください。
https://raw.githubusercontent.com/cometscome/JHPCN2027_QandA/main/skills/jhpcn-call-qa/SKILL.md
募集要項PDF：https://jhpcn-kyoten.itc.u-tokyo.ac.jp/files/pdf/Call_for_Proposal_2027J_ver.1.pdf

根拠となる節・ページを示してください。申込書の記入方法に限り、スキル記載のWord・Excelも参照してください。一般のWeb検索や外部の料金表で補わないでください。

募集要項第1版の要点（リンクを開けない場合もこの範囲で回答できます）：
・第9.1節（冊子pp.13–14）：1課題の計算資源の申請上限は金額換算で、単独拠点のみ（mdxを除く）300万円、複数拠点は合計360万円、mdxのみ100万円。複数拠点でmdxを含む場合、mdx分は100万円と「360万円から他拠点分を引いた残額」の小さい方まで。
・第9.3節（冊子p.15）：採択後の提供量は予算により申請量から削減される場合があります。

計算資源の規模や金額を聞かれたら、上記の申請上限を条件付きで先に答えてください。追質問にも直前の話題を引き継いでください。原本を開けず上記の要点を使った場合はそう明記し、要点を超える質問には必要なファイルの添付を求めてください。

質問：リソースはいくら分提供されますか？
```

同じ会話で「この上限には、GPUとストレージの両方が含まれますか？」と続けられます。スキルのリンクを開けない環境では[スキル本文](skills/jhpcn-call-qa/SKILL.md)をコピーしてください。様式の中身を直接読めない場合は、下記のWordまたはExcelをチャットに添付してください。

## 資源量についての回答例

**リソースはいくら分提供されますか？**  
1課題で申請できる計算資源は、**単独拠点の資源のみ（mdxを除く）なら300万円相当まで、複数拠点なら合計360万円相当まで**です。mdxのみなら100万円相当までです。GPUを希望する場合も、これらは課題で申請する資源全体の上限です。複数拠点でmdxを併用する場合、mdx分は100万円と「360万円から他拠点分を引いた残額」の小さい方が上限です。採択後に提供される資源量は、予算により申請量から大幅に削減される場合があります。[募集要項 第9.1節（冊子pp.13–14）](https://jhpcn-kyoten.itc.u-tokyo.ac.jp/files/pdf/Call_for_Proposal_2027J_ver.1.pdf#page=17)・[第9.3節（冊子p.15）](https://jhpcn-kyoten.itc.u-tokyo.ac.jp/files/pdf/Call_for_Proposal_2027J_ver.1.pdf#page=19)

## 申込書についての質問例

- Wordの「研究の学際性・資源利用の必要性」には、どんな内容を記述するよう求められていますか？
- Wordの本文にかかるページ数制限と、「資源量積算根拠と利用目的」の扱いを教えてください。
- Excelのどのシートに共同研究メンバーを記載しますか？ 量子コンピュータを利用する人は、どの欄に何を記入しますか？
